Description

This project is a menu-driven calculator built using Java. It provides an interactive interface where users can choose an operation, input numbers, and receive results instantly. The application ensures a smooth user experience by handling invalid inputs and edge cases like division by zero.

Features : 
- Supports basic arithmetic operations such as addition, subtraction, multiplication, and division
- Menu-driven interface for easy user interaction
- Handles invalid input using exception handling
- Prevents division by zero errors
- Allows users to perform multiple calculations in one session
- Structured and clean code using methods
